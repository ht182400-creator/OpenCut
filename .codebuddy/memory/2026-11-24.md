## UI 长尾：书签拖动 / 备注（用户指定）

### 调研

- `changelog/0.1.0.md:16` 权威说明经典版书签支持 notes / color labels / optional duration；本工程按 `{id,ticks,name,note?}` 透传（core `scene.bookmarks` 是 `serde_json::Value` 原样写回），颜色标签/时长不伪造。
- Chrome 官方拖动指南：pointer capture + 4px 阈值 + `touch-action:none`/`user-select:none`，用于避免移出元素丢事件与触摸滚屏。

### 实现

- 新 `bookmark-model.ts` 纯函数：`draggedBookmarkTicks`（复用 `timelinePixelsToTicks`，按 tick 网格吸附、clamp≥0）/ `moveBookmark` / `setBookmarkNote`（空备注删 note 字段 additive-only）+ 10 项单测。
- `timeline.tsx`：书签行 pointerdown/move/up/cancel（拖动基准 ref + 4px 阈值 + setPointerCapture）、双击 inline input 备注（回车/blur 提交、Esc 取消）、显示/标题含 note、cursor grab。
- 类型链路加可选 `note`：`project-autosave.ts`（校验非法 note 整条作废）、`project-write.ts`（读取透传、非法 note 书签丢弃）、`editor-actions.ts` / `editor-page.tsx` / `timeline.tsx`。

### 验收

- tsc 0；书签相关 3 文件 39/39；全量 vitest **41 文件 497/497**（原 484 + 新 13）；vite build 成功（dist 时间戳确认）。
- 浏览器（agent-browser）：添加书签 → 双击弹出备注框 → 填「开场提示」并 blur 提交 → 书签显示 `◆ 书签 1 · 开场提示`；mouse 拖动 100px → left `0px→98.58px`、autosave `ticks=128000, note=开场提示`；截图 `roadmap/oc-bookmark-drag-note.png`。
- `FEATURE_PARITY.md` §3 书签 🟡→✅，统计重核算 41/6/5/15，§10 追加完成说明。

### 踩坑

- 测试预期按实际修正：`timelinePixelsToTicks` 对 zoom≤0 回退 zoom=1（故拖动 zoom=0 仍有位移），帧吸附实测 14000 非手算 12000；`bookmarksFromProject` 对非法 note 整条丢弃（与 NaN ticks 防御一致），预期随之更新。
- agent-browser `keyboard press` 不支持（仅 type/inserttext），改用 `eval(...blur())` 触发提交；`screenshot` 用位置参数而非 `--path`。

### 边界

- 颜色标签 / 可选时长未做（经典版 changelog 提及但本工程无 schema 依据，不伪造）；note 非法类型整条丢弃（不静默吞损坏数据）。
