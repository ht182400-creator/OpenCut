## W-14 批 8：桌面撤销/重做快照栈

### 背景

- 用户「继续」：承接 2026-11-22 批 7（另存为），按 ADR-04 过渡态继续补桌面 P0 缺口。
- 探查结论：桌面端缺失 Web 已闭环的撤销/重做（`clip-history`）与时间轴编辑；core 侧 `ocx-domain` 的 ripple / 写回 API 已就绪但桌面零接线。
- 本批先做「编辑安全网」撤销/重做，为后续时间轴编辑提供回滚能力。

### 实现

- 新模块 `apps/desktop/src/_project_history.rs`（220 行）：`HistorySnapshot`（完整 `ProjectView` 克隆 + 播放头 + 选中 id + 动作说明）、`ProjectHistory`（`new` / `push` / `travel` / `can_undo` / `can_redo` / `label`），`MAX_HISTORY_ENTRIES = 50` 命名常量；`push` 丢弃 redo 分支并按容量裁剪；`travel` 返回克隆避免与宿主状态借用冲突。4 项纯函数单测覆盖初始态、撤销/重做逐字段恢复、redo 分支丢弃、容量裁剪。
- `project.rs`（984 行）：新增 `history` 字段并在 `load` 初始化；`commit_edit` 在变化时 push 快照（label 复用此前 `#[allow(dead_code)]` 的 `EditableField::label()`，dead_code 提示消除）；新增 `undo` / `redo` / `apply_snapshot` / `history_label`。
- `shell.rs`：`handle_key` 增 `undo` / `redo` 参数，键盘事件解析 Ctrl+Z / Ctrl+Shift+Z；仅普通态响应（编辑态/另存为态优先），恢复成功后自动写回，与编辑提交行为一致。
- `inspector.rs`：EDIT_HINT 补撤销/重做提示；面板显示历史摘要（如 `1 / 1 步 · 打开项目` + 方向箭头）。
- `main.rs`：注册 `mod _project_history`。

### 踩坑

- 新模块未在 `main.rs` 注册导致 `E0432 unresolved import crate::_project_history`；补 `mod _project_history;` 后通过。
- `ProjectView` 在结构体字面量中先于 `history` 字段移动，需先构造 `let history = ProjectHistory::new(&view, 0, None);` 再进入 `Ok(Self { view, ... })`。

## W-14 批 9：时间轴编辑（删除/分割/裁剪）

### 背景

- 用户「继续」：批 8 已建立撤销/重做安全网，本批补桌面 P0 缺口「时间轴编辑」。
- 探查结论：core `ocx-domain::ripple` 只操作最小 `TimedElement`（id/起点/时长），桌面必须保留 v31 `ElementView` 的 trim/name/mediaId/params 全字段，转换会丢数据；故在 `ProjectView` 层实现等价语义。
- `project.rs` 已达 984 行，本批零改动该文件，全部逻辑与状态接线放新模块。

### 实现

- 新模块 `apps/desktop/src/_timeline_edit.rs`：`TimelineEdit` 枚举（Delete / Split / TrimIn / TrimOut）、`TimelineEditError` 三种拒绝原因（中文 Display）；纯函数 `edit_view` 在 `ProjectView` 上实现删除（同轨后续 ripple 前移 + `element_count` 同步）、分割（播放头一分为二、id 加 `#2` 后缀去重、后半段 `trim_start` 累加）、入点（head trim）、出点（尾部裁剪），最小片段一帧；`apply_to_state` 完成状态接线、历史快照记录与自动写回。4 项纯函数单测覆盖拒绝分支、删除 ripple、分割总时长与 id 唯一、入出点 trim 语义。
- `main.rs` 注册模块；`timeline.rs` 信息条加「删 / 分 / 入 / 出」四按钮；`shell.rs` 的 Delete / S / I / O 快捷键走同一入口；`inspector.rs` 提示栏补快捷键。
- 编辑成功后立即写回，与字段编辑提交行为一致；内嵌演示项目无路径时给友好提示。
