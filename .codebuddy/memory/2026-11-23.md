## W-14 批 9：时间轴编辑（删除/分割/裁剪）

### 背景

- 用户「继续」：批 8 已建立撤销/重做安全网，本批补桌面 P0 缺口「时间轴编辑」。

### 实现

- 新模块 `_otio_io.rs`：`ProjectView` ↔ `EditTimeline` 映射（视频轨非 Gap/Transition 片段 → `ElementView`，主轨 → 单轨 OTIO）；`--otio <path>` / `--otio=<path>` / `OPENCUT_OTIO` 路径解析；`OtioDesktopError` 六种中文友好错误；`apply_import` 记录历史并写回；`apply_export` / `export_to_status` 导出到项目同目录 `<项目名>.otio`。
- `main.rs` 注册模块；`project.rs` 仅把 `file_path` 改 `pub(crate)`（1 行，985 行仍在 1000 内）。

- `import_into_view` 用 `iter_mut().find().or_else(iter_mut())` 触发二次可变借用冲突；改为先不可变扫描定位 `(scene, track)` 索引再按索引取可变借用。
