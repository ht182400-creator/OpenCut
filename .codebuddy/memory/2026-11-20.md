## 批次 1：框选橡皮筋（已完成，待提交）

### 交付

- `element-operations.ts` 新增纯函数 `selectFromBox(context, hitIds, additive)`：普通框替换命中集合、Shift 加框取并集、空框清空/保持、按时间轴顺序、忽略未知/重复 id。
- `use-selection.ts` 暴露 `handleBoxSelect(hitIds, additive)`，复用 `applySelection` 同步主选中/锚点，并提示「框选 N 个片段」。
- `classic-ui/timeline-tokens.ts` 新增 `timelinePixelsToTicks`（ticks→px 逆运算，非法入参回落 0）、`normalizeTimelineRect`（支持反向拖拽）、`rectsIntersect`（边界接触算相交、零面积 false）、常量 `TIMELINE_LAYERS.marquee=50` 与 `TIMELINE_MARQUEE_MIN_PX=4`。
- `classic-ui/timeline.tsx`：新增框选状态/ref（起点、当前矩形、渲染快照），轨道空白处 mousedown 启动框选（无 `onBoxSelect` 时退回定位播放头），全局 mousemove 画矩形，mouseup 按矩形与片段几何求交回调。模块级纯函数 `collectMarqueeHits` 便于单测。渲染 `.classic-timeline-marquee`，`theme.css` 加对应样式。

### 关键踩坑

- **坐标系偏差**：框选矩形 y 是相对滚动视口的内容坐标（含 ruler 22px + bookmarks 16px = 38px 顶部偏移），而片段 top 从 tracks 容器算起（`getCumulativeHeightBefore + padding`）。首轮浏览器验收框 main 轨误判到 audio 轨——因两者差 38px。修正：`collectMarqueeHits` 内把框选矩形 y 减去 38px 后相交判定。
- **stale closure**：`useEffect([])` 的全局 mouse 监听读 state 会取到旧值。改用 `marqueeStartRef`/`marqueeRectRef`/`marqueeDataRef`/`boxSelectRef` 保存起点、矩形、渲染快照、回调。
- **测试期望算错**：`timelinePixelsToTicks(24,3,30000)` = 24/(50×3)×30000 = 4800（非 48000），已更正；`TIMELINE_LAYERS` 新增 marquee 后更新 token 断言。
- **build 竞态**：CodeBuddy safe-delete shim 清理 `dist/client/.assetsignore` 时报「文件不存在」，与代码无关；手动 `[System.IO.Directory]::Delete(dist,true)` 后重建成功。
