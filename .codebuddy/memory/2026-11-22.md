- `shell.rs`：启动按「命令行 → 环境变量 → 内嵌 fixture」链加载；文件不存在/解析失败不再 panic，而是回退演示项目并把 `⚠ 打开 xxx 失败：…（已加载演示项目）` 展示在 Browser。
- `browser.rs`：显示项目来源标签与加载错误提示。
- `timeline.rs`：信息条保留逐帧/播放按钮，新增整秒刻度、`relative()` 比例播放头进度条、按轨道分组的片段条（spacer 填充 `start` 前空白、片段宽 = `duration/total`、尾部补空、选中高亮）。

## 踩坑

- 测试路径：`env!("CARGO_MANIFEST_DIR")` 是 `apps/desktop`，fixture 相对路径应是 `../web/...`（不是 `../../web/...`），否则找不到文件。
- GPUI 0.2.2 无 CSS 式 absolute/relative 定位：改用 `relative(f32)` 作宽度比例 + flex spacer 实现时间轴布局。
- 生命周期错误：`on_click` 是 `'static` 闭包，不能捕获借自 `snapshot` 的 `element`；把 `start_time`/`id`/`label` 提前 clone 成拥有值。同理 `project_entity` 需在闭包外 clone。
